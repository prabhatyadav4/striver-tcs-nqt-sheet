## 🏢 About TCS NQT

**TCS NQT (National Qualifier Test)** is an online assessment conducted by **Tata Consultancy Services** for hiring freshers from campuses across India. It is one of the most widely taken placement exams in the country.

### Exam Pattern (Coding Section)

| Parameter | Details |
|-----------|---------|
| Number of Questions | 1–2 coding problems |
| Difficulty | Easy to Medium |
| Time Limit | 30–60 minutes |
| Languages Allowed | C, C++, Java, Python, and more |
| Negative Marking | None |

### Topics Frequently Tested

- Array manipulation and searching
- String operations and pattern matching
- Basic number theory (prime, factorial, fibonacci)
- Number system conversions (binary, octal, hex)
- Sorting algorithms and their applications

## 💡 Tips to Crack TCS NQT Coding Section

- ✅ Focus on writing **correct and complete** solutions — partial marks may not be awarded
- ✅ Practice writing code **without an IDE** to simulate exam conditions
- ✅ Understand the **time and space complexity** of your solutions
- ✅ Solve all 100 questions in this sheet before the exam
- ✅ Revise **edge cases** — empty input, negative numbers, large values
